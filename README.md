# myfirstportfolio_Rodriguez
myfirstportfolio_Rodriguez

Project Overview

This project is a personal portfolio website created to showcase my web development skills, education, projects, and graphic design work. It highlights what I have learned so far as a college student studying Graphic Information Technology at Arizona State University.

Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Media Queries
* Git and GitHub

Website Pages

* **Home:** Introduction and links to explore my work.
* **About Me:** Background, interests, and goals in web development.
* **Projects:** Web development projects and graphic design work.
* **Education & Skills:** Education, technical skills, and current learning goals.
* **Contact:** Ways to get in touch with me.

Features

* Responsive layout for different screen sizes.
* Navigation links connecting all website pages.
* Consistent colors, typography, and styling throughout the website.
* Project sections featuring images and descriptions.
* Interactive link styling with hover effects.
* Organized layouts using CSS Grid and Flexbox.

What I Learned

Through this project, I practiced organizing a multi-page website with HTML and styling it with CSS. I also worked with responsive design, navigation, image formatting, and hover effects to make the website easier to use across different screen sizes.
