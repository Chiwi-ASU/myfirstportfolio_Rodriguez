A Little About Me

I'm a third-year college student at Arizona State University pursuing a bachelor's degree in Graphic Information Technology. I'm interested in the connection between technology and visual design.

I became interested in web development because I like seeing code come to life. I enjoy the idea of starting with lines of code and turning them into something people can see and interact with.

What I'm Learning

Through my coursework, I've been learning different programming and design tools. I'm continuing to build my skills and explore the areas of technology that interest me most.

  • HTML and CSS for building and styling webpages
  • Java and Python for programming
  • Git and GitHub for version control and managing code
  • Adobe Photoshop and Illustrator for visual design

My Goals

I'm still exploring my long-term career goals, but web development is an area I'd like to continue learning about. For now, my goal is to keep practicing, work on new projects, and become more confident in both my technical and design skills.
