Waters R Us

Waters R Us is a playful webpage about the different forms of water: liquid, gas, solid, and clouds. I used HTML to organize the content into sections and create navigation links that jump to different parts of the page. I used CSS to style the header, navigation, typography, and image gallery, along with flexbox and grid to organize the layout.

Technologies: HTML, CSS
